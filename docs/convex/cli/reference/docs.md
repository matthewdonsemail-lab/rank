# `npx convex docs`

Open the docs in the browser

## Syntax[​](#syntax "Direct link to Syntax")

```
npx convex docs [options]
```

## Options[​](#options "Direct link to Options")

* `--no-open`

  Print docs URL instead of opening it in your browser
