# Deployments

> For AI agents: see [llms.txt](/llms.txt) for the complete documentation index. Markdown versions are available by adding .md to a page URL or requesting Accept: text/markdown.

Each project in Convex has a main production deployment, and each developer on your team can also set up their own personal development deployment. Additionally, there are [preview deployments](/production/multiple-deployments.md#preview) used to test backend changes before they're deployed to production.

While on a [deployment page](https://dashboard.convex.dev/deployment), you may switch between production, your development deployment, and any preview deployments by clicking the deployment's name at the top-left of the page. Each deployment is listed by its reference (`production`, `dev/<your name>`, or `preview/<branch>`) above the deployment's name, and typing filters the list.
